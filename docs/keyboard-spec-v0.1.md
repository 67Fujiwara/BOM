# BOMツール キーボード専用（プロ仕様）仕様書

- 版：v0.1（2026-10-22）
- 対象：Web BOMツール（B案「キーボード完結のプロ仕様」を全面採用）
- 対象範囲：**電気部品のみ**（メカ部品は扱わない）

---

## 1. 目的

購買への提出を **1回で通す**。指摘が来ても、資料を作り直さずに **表示の切り替えと並び替えだけで回答** できるようにする。

そのために、すべての操作をキーボードだけで完結させる。マウスに持ち替える時間をなくし、作業工数を限りなくゼロに近づける。

## 2. 基本方針

1. **マウス不要**：表示・入力・確定・出力・案件切り替えまで、すべてキーボードでできる。マウス操作は残すが、キーボードに劣る操作は作らない。
2. **2つのモードだけ**：表の中は「ナビモード（移動と操作）」と「編集モード（セル入力）」の2つ。今どちらかは常に画面下に表示する。
3. **1キー操作はナビモードだけ**：`a` や `o` などの1キー操作は、ナビモードでしか効かない。編集中に誤爆しない。
4. **迷ったら `Ctrl+K`**：すべての操作はコマンドパレットから名前で実行できる。ショートカットを覚えていなくても使える。
5. **すべて取り消せる**：どの操作も `Ctrl+Z` で戻せる。確認ダイアログで止めない。
6. **ブラウザ予約キーは使わない**：`Ctrl+W` `Ctrl+T` `Ctrl+N` `Ctrl+Tab` などは割り当てない。

## 3. 画面構成

```
┌──────────────────────────────────────────────────────────────┐
│ 案件ID 案件名   納期 あと29日        ● エラー4  ● 警告9   Ctrl+K │ ← ヘッダー
├──────────┬───────────────────────────────────────────────────┤
│ ビュー     │ 表（BOM本体）                                       │
│ 1 すべて   │  ID   部品名   型式   メーカ  数量  採用  金額  納期  状態 │
│ 2 購買提出 │  ▸ 行を開くと相見積の比較・履歴が下に展開              │
│ 3 発注入荷 │                                                   │
│ 4 要確認   │                                                   │
│ 5 変更あり │                                                   │
│ 6 商社別   │                                                   │
├──────────┴───────────────────────────────────────────────────┤
│ ナビ │ R034 型式 │ a 採用  o 発注  r 置換  ? ヘルプ           │ ← ステータスバー
└──────────────────────────────────────────────────────────────┘
```

- **ヘッダー**：案件ID・案件名・納期の残り日数・エラーと警告のランプ・コマンドパレットの入口。
- **左のビュー一覧**：数字キー `1`〜`6` で切り替える。各ビューの件数を表示する。
- **表**：選択中のセルは太い枠で示す。行は選択中、セルは編集中で色を変える。
- **ステータスバー**：今のモード、選択中の行とセル、その場で使える主なキーを常に表示する。

## 4. モード

| モード | 入り方 | 出方 | できること |
| --- | --- | --- | --- |
| ナビ | `Esc`（編集から） | `Enter` / `F2` / 文字入力 | セル移動、1キー操作、ビュー切り替え |
| 編集 | `Enter` / `F2` / いきなり文字を打つ | `Enter`（確定して下へ）、`Tab`（確定して右へ）、`Esc`（取り消し） | セルへの入力、候補の選択 |
| パレット | `Ctrl+K` | `Enter`（実行）、`Esc`（閉じる） | 名前で操作を探して実行 |

- ナビモードで文字を打つと、そのまま編集モードに入って上書き入力になる（Excelと同じ）。
- 選択式のセル（単位・調達区分・状態）は、編集モードで頭文字を打つと候補が絞り込まれる。例：単位で `p` → パック。

## 5. キーマップ

### 5.1 全体（どのモードでも効く）

| キー | 操作 |
| --- | --- |
| `Ctrl+K` | コマンドパレットを開く |
| `Ctrl+P` | 案件を切り替える（保存中の案件を検索して開く） |
| `Ctrl+S` | 一時保存（自動保存に加えて、明示的に保存） |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 元に戻す / やり直す |
| `Ctrl+E` | Excelで出力 |
| `Ctrl+Shift+C` | 表示中の行と列を、書式つきでコピー |
| `Ctrl+G` | ID・型式・Noを入力して、その行へジャンプ |
| `/` | 絞り込み検索にフォーカス（ナビモードのみ） |
| `?` | ショートカット一覧を表示（ナビモードのみ） |
| `Esc` | 1段階戻る（編集を取り消す → パネルを閉じる → 選択を解除） |

### 5.2 移動（ナビモード）

| キー | 操作 |
| --- | --- |
| `↑` `↓` `←` `→` | セルを移動 |
| `J` / `K` | 次の行 / 前の行（行単位の操作向け） |
| `Tab` / `Shift+Tab` | 右のセル / 左のセル |
| `Home` / `End` | 行の先頭のセル / 行の最後のセル |
| `Ctrl+↑` / `Ctrl+↓` | 表の先頭 / 表の最後 |
| `PageUp` / `PageDown` | 1画面ぶん上 / 下 |
| `Space` | 行を開く・閉じる（相見積の比較と変更履歴）。分類の見出し行では折りたたみ |
| `1`〜`6` | ビュー切り替え（すべて・購買提出用・発注入荷・要確認・変更あり・商社別） |
| `[` / `]` | 前の分類 / 次の分類へ |

### 5.3 編集（ナビモードで行・セルに対して）

| キー | 操作 |
| --- | --- |
| `Enter` / `F2` | セルを編集 |
| `Delete` | セルを空にする |
| `Shift+Enter` | 下に行を追加して、部品名の編集に入る |
| `Shift+D` | 行を複製 |
| `Shift+Delete` | 行を削除（`Ctrl+Z` で戻せる） |
| `Alt+↑` / `Alt+↓` | 行を1つ上 / 下へ移動 |
| `Ctrl+C` / `Ctrl+V` | セルのコピー / 貼り付け。Excelからの複数セルの貼り付けにも対応 |
| `Ctrl+D` は使わない | ブラウザのブックマークと衝突するため |

### 5.4 BOM操作（ナビモード）

| キー | 操作 |
| --- | --- |
| `a` | 最安の商社で採用（単価・納期も反映） |
| `Shift+A` | 商社を選んで採用（相見積の一覧が開き、`1`〜`9` で選ぶ） |
| `r` | 置き換え品を作る（元の行は不採用、新しい行は型式の編集から） |
| `o` | 発注済の切り替え |
| `i` | 入荷済の切り替え（オンにすると発注済も自動でオン） |
| `h` | 行を隠す / 隠すのをやめる |
| `s` / `Shift+S` | 今の列で並び替え（昇順 / 降順）。もう一度押すと解除 |
| `f` | 今のセルの値で絞り込み（例：商社のセルで `f` → その商社だけ） |
| `c` | 列の表示パネルを開く（`↑` `↓` で選び、`Space` で表示を切り替え） |

### 5.5 チェック（ナビモード）

| キー | 操作 |
| --- | --- |
| `n` / `Shift+N` | 次の問題 / 前の問題のセルへジャンプ |
| `Ctrl+.` | 今の問題をその場で直す（直し方の候補を出す。例：前後の空白を削除、入数を入力） |
| `x` | 警告を「確認済み」にする / 確認済みを外す |
| `Ctrl+Shift+F` | 「順番に直す」モード（残りの問題を1件ずつ表示し、`Enter` で直して次へ） |

## 6. コマンドパレット（`Ctrl+K`）

- 入力した文字で、操作・行・案件を同時に検索する。
- **文の形で打てる**：`R034 採用` → 「R034 を因幡で採用 ¥8,040 最安」が先頭に出て、`Enter` で実行。
- 主なコマンド：
  - `<ID> 採用 [商社名]`、`<ID> 置換`、`<ID> 発注`、`<ID> 入荷`、`<ID> 隠す`
  - `出力`、`コピー`、`提出として記録`
  - `ビュー <名前>`、`今の表示をビューとして保存`
  - `商社を追加 <名前>`、`ルールを追加`
  - `案件 <ID または名前>`、`新しいBOM`
  - `未採用を最安で一括採用`
- 候補の右端に、その操作のショートカットを表示する（自然に覚えられるようにする）。
- 最近使ったコマンドを上に出す。

## 7. 主な流れのキー操作

### 7.1 新しいBOMを作る

`Ctrl+K` → `新しいBOM` → ガイドが開く。

1. 案件ID → `Enter`
2. 案件名 → `Enter`
3. 納期（`未定` と打てば未定）→ `Enter`
4. 送付先（候補を `↓` で選択）→ `Enter`
5. 相見積先（`↑` `↓` で移動、`Space` で選択、`Enter` で次へ）
6. 部品の入れ方（`1` 貼り付け、`2` ファイル、`3` 1つずつ入力）
7. チェック（問題を1件ずつ。`Enter` で直して次へ、`x` で確認済み、`Shift+→` であとで）

`Alt+←` でいつでも1つ前の段階に戻れる。

### 7.2 購買から指摘が来たとき

1. `4` で「要確認」ビュー、または `n` で問題のセルへジャンプ。
2. `Enter` で直すか、`Ctrl+.` で直し方の候補から選ぶ。
3. 指摘が新しい種類なら、`Ctrl+K` → `ルールを追加`。次から自動でチェックされる。
4. `2` で「購買提出用」ビュー → `Ctrl+E` で出力（変更点シートは自動で付く）。

### 7.3 相見積から採用まで

1. `2` で「購買提出用」ビュー。
2. `Space` で行を開き、商社ごとの金額と納期を比較。
3. `a` で最安を採用、または `Shift+A` → `1`〜`9` で商社を選んで採用。
4. 全部まとめるなら `Ctrl+K` → `未採用を最安で一括採用`。

### 7.4 発注・入荷

1. `3` で「発注・入荷」ビュー。
2. `J` `K` で行を移動しながら、`o` で発注済、`i` で入荷済。

## 8. 引き継ぐ既存機能

今の試作版の機能は、すべてそのまま残す。

- 固定の行ID（R001〜）
- チェックルール（画面から追加でき、全案件で共通）
- 提出記録と変更点の自動抽出
- 相見積（商社の追加・名前変更・並び替え・色）
- 発注済・入荷済のチェック
- 複数案件の保存と切り替え
- Excelの取り込み（貼り付け・ファイル）
- Excel出力（BOM・変更点・チェック結果の3シート、列幅と色つき）
- 書式つきコピー

## 9. 受け入れ基準

- [ ] 新規作成から、Excel出力まで、マウスに一度も触らずに完了できる
- [ ] すべての操作がコマンドパレットから名前で実行できる
- [ ] 1キー操作は、編集モード中に一切反応しない
- [ ] 今のモードと選択中のセルが、常に画面上で判別できる
- [ ] どの操作も `Ctrl+Z` で戻せる
- [ ] `?` のヘルプに、本書のキーマップがすべて載っている
- [ ] フォーカスが見えなくなる・抜け出せなくなる場面がない
- [ ] 日本語入力の変換中（`Enter` で変換確定するとき）に、ショートカットが誤作動しない
- [ ] 80行のBOMで、キー入力から画面の反応まで 50ミリ秒以内

## 10. 実装メモ

- キー判定は `event.key` で行い、`event.isComposing` が真のときは何もしない（日本語入力の誤爆防止）。
- キーマップは1か所の定義表にまとめ、ヘルプ画面・パレットの表示・ステータスバーをそこから自動生成する。
- 将来、キー割り当てをユーザーが変更できるようにする（定義表をJSONで保存）。
- 規模が大きくなるので、単体HTMLから Claude Code での本格実装に移行する。

## 11. 決めていないこと

- 「Vim風」の操作（`hjkl` 移動、`dd` 削除など）を別モードとして用意するか
- `Ctrl+E`・`Ctrl+P` を、ブラウザ側の動作より優先してよいか（社内で使うブラウザで要確認）
- スマホ（入荷スキャン）向けの操作をどこまで入れるか
