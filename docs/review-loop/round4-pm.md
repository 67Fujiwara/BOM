## 3. 新規 AMBIGUOUS

### NA1. 「対策不成立」の行が発注済のとき、決定パネルの `b` 次点へ が有効か（§9.1 の 2 行が同時に当たる）
- シナリオ：S6（先行発注済みの行に納期NG → `d` 代替品検討 → 設計「代替なし」）
- 何が起きるか：§9.1 の「納期NG（発注済）」行は「`b` `p` は無効」と明記しているが、「対策不成立」行は発注前後を区別せず `b` 次点へ / `g` 再交渉 / `e` 特急・分納 を列挙している。発注済の行が対策不成立で再掲されたとき、どちらの行の選択肢を出すかが二通りに読め、`b` を有効にすると発注済の行に次点商社を自動選定（二重発注の芽）になる。
- 修正案：§9.1 の対策不成立の行を「対策不成立（発注前）：受入 / `b` / `g` / `e`」「対策不成立（発注済）：受入 / `e`（特急・分納・納期短縮交渉）。`b` `g` は無効」に分けるか、1 文「対策不成立でも発注済の行は納期NG（発注済）の選択肢に従う」を加える。§16 にも 1 行追加。
