## 3. 新規 AMBIGUOUS

### NA4-01 `9` 購買作業ビューで、再見積要の行に対する `Enter` が「セル編集」か「据え置き/再見積のパネル」か
- **シナリオ**：S5（再見積要の行に、商社から電話で聞いた再見積単価を手入力したい）
- **二通りの読み**：§4 再見積要の外れる条件「`5`/`9` の行で `Enter` → `1 据え置き / 2 再見積`」。keyboard-spec では `Enter` ＝ セルを編集。`9` は購買の入力ビューなので、単価セルで `Enter` を押したとき編集に入るのかパネルが開くのかが読めない（`5` は差分確認ビューなのでパネルで自然だが、`9` では衝突する）。
- **修正案**：`9` ではセルの `Enter` は編集のまま、パネルは「状態/フラグ列のセルで `Enter`」または `Ctrl+.`（直し方の候補。要再確認と同じ導線）に限定すると §4 に明記。

### NA4-02 納期NG（発注前）の `b` 次点へ（自動）の「次点」の定義
- **シナリオ**：S6（PM が納期NG の行で `b` を選ぶ）
- **二通りの読み**：差分超過の `b` は「スコア 2 位」で期限切れ時の確認も書かれているが、納期NG の `b` は「次点へ（自動）」とだけある。スコア 2 位と読むと、2 位も必要日を満たさない場合に納期NG が再び立って `7` に戻る（ループ）。「必要日を満たす商社のうち最高スコア」とも読める。期限切れの扱いも書かれていない。
- **修正案**：納期NG の `b` は「必要日を満たす（余裕日 ≥ 0）商社のうち最高スコア。該当なしまたは期限切れなら `1 再見積してから / 2 特急・分納へ` を確認」と §9.1 に明記。

### 文面整合（カウント外。§16 の決めと旧文言が残っている箇所。実装者は §16 を正とすればよい）
- §4 フラグ表「先行発注判断：PM の `l` 許可」と §14「決定パネル … `l`」→ §9.1/§16 は `y` のみ・`l` は使わない。
- §4 フラグ表「要再確認：指摘対応（型式あいまい・メーカ未記入）」→ §6.3/§16 は種別を問わず。
- §6.2 代替提案の起票不可「代替不可」、§7「代替可否＝不可の行は生成せず」→ §3.1/§16 の「メーカ指定＝任意の行のメーカ埋めは代替提案として生成」を例外として添えると読み違えが無くなる。
