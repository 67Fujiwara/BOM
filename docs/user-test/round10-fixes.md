| U10-01 / U10-02 / U10-04 | 見積中に戻した行数が違う、全社辞退で次の手が無い、ヒントが「相見積先すべて」だけ | 実際に戻した行だけ数える。全社辞退は「設計に代替を相談（指摘）」。ヒントは依頼先の選び方を両方書く |
