## 2. 新しい不具合

形式：重大度 / 再現（キー列）/ 期待 / 実際 / 証跡 / 推定原因

### N16-01 【悪化】変えた行だけ変更後を書く変更図で、**変えた行の新の列を全部書く**（変えていない数量・メーカーも新の列に写す）と、変えていない部品が全部「削除」として BOM から消える。「変更なし」「同左」と明記した行も消える
- 重大度：**重大**（設計変更の様式は「変えた行は変更後の欄を全部埋める」書き方が普通。1 行でも新と旧が同じセルがあると、新の列が空の行がすべて削除扱いになり、残りの 1 行だけで Rev.1 公開される。購買の画面にも 1 行しか出ない。知らせは「新しい版の列が空で前の版だけに値がある 3 行（例: タイマ H3CR-A8 1）は、削除された部品として取り込みません」と言い切るので、新人は削除だと信じる。r15 のビルドでは全行を取り込んでいた）
- 再現：ガイド → `1`（貼り付け）→「品名｜型式（旧）｜型式（新）｜メーカー｜数量（旧）｜数量（新） / リレー｜MY2N｜MY4N-D2｜オムロン｜2｜2 / タイマ｜H3CR-A8｜（空）｜オムロン｜1｜（空） / ブレーカ｜NF32-SV｜（空）｜三菱電機｜1｜（空） / 端子台｜XW2B-20G4｜（空）｜オムロン｜4｜（空）」→ `Ctrl+Enter` → `Enter` → `Ctrl+Enter` → 役割を購買に。xlsx の設計変更の様式（上の段「変更前｜変更後」を結合、c1）、「メーカー（旧）｜メーカー（新）」で変えた行のメーカーを写した表（c2・A2）、2 段の「変更前／変更後」（A3）も同じ
