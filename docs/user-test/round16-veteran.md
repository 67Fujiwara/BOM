### V16-01 変えた行だけ「変更後」を書く表で、変えた行のほかの変更後の列（メーカ・数量）に変更前と同じ値を書き写してあると、変えていない行をすべて「削除された部品」として取り込まない【ラウンド15 の修正（V15-02・N15-02 の「全部の行に書いた表」の判定）の副作用・悪化】
- 重大度：**重大**（設計変更の様式で「変更後」の欄（型式・メーカ・数量）を、変えた行だけまとめて埋める書き方はふつう。300 行のうち 30 行だけ型式を変えた .xlsx が **30 行の BOM** になる（270 行が消える）。知らせ「新しい版の列が空で前の版だけに値がある 270 行（例: 部品1 OLD-1 三菱電機）は、削除された部品として取り込みません」は出るが、プレビューの件数は「取り込む行: 30 行」で、そのまま作成すると 30 行。r15 ビルドは 300 行）
- 再現
  - 「部品名・型式・変更後型式・メーカ・変更後メーカ・数量」：リレー MY2N→MY4N（メーカ オムロン→オムロン と書き写した）、端子台 XW2B（変更後は空）、ヒューズ F-10（変更後は空）→ **リレーの 1 部品**（SP1）

## 3. 使い勝手（不具合ではないが、ベテランが引っかかる点・確認できた良い点）

1. **macOS の欄の中の Control+英字**（`111-mac-ctrl`・`114-mac-ctrl-typed`、navigator.platform を MacIntel にして 2 回）：Control+D は編集中・パレット・絞り込みの欄で既定動作を止めなくなり（ラウンド15 の修正どおり。Cmd+D は止める・表の上の Control+D は「Ctrl+D はありません」の知らせ）、打っている途中の文字も残る。ただし macOS の欄で同じく指が覚えている **Control+E（行末）・Control+K（行末まで消す）・Control+F（1 字進む）・Control+P（前の行）** は、編集中なら打っていた値を確定してから 書き出し・パレット・絞り込み・受信箱を開く（値は失われない）。Control+A・B・N・H・T は何もしない（既定動作は止めない）。macOS では Cmd の操作だけをアプリのキーにし、Control+英字は欄の中では欄に任せると、ラウンド15 の Control+D と揃う（`src/keys/keymap.ts:109` の `ctrl = e.ctrlKey || e.metaKey`）。ヘッドレスの Chromium は Emacs 風の操作をしないので、実機の動きは確かめていない（環境依存）
2. **タブの複製**（同じタブから開いたタブは Ctrl+Z の履歴を写し持つ。`113-dup-tab`）：B で公開を戻したあと、A でも同じ公開を Ctrl+Z すると、もう一度「公開済の値を戻しました…1 行に積みました」と出る（値は同じで二重には積まない。D1、両ビルド）。別のタブが公開し直した行の公開は A・B どちらも戻さない（D3。r15 ビルドは A が B の Rev.3 を戻していた＝V15-09 の修正で直った）
3. **号機ごとの数量の列が 1 段の見出し「1号機・2号機・合計」**（数量の語なし）は、数量の列が無いとして全部 1（知らせあり）（GO4、両ビルド）。2 段や「数量(合計)」なら合計を使う
4. **仕様・規格の列**（「品名・仕様・数量・単価・金額」「部品名・規格・メーカ・単価・数量」）は取り込まずに捨てる（型式が空の部品）。見積書の形では仕様が型式の代わりのことが多いので、型式の列が無いときは仕様・規格を型式に入れるか「仕様の列は取り込みません」と知らせる（H1・H7、両ビルド）
5. **JSON の読めない文字の数**（「¥1,200-」「1200円(税別)」「▲500」「−5」（U+2212）「1e3」「abc」「TBD」）は黙って空（K2〜K4、両ビルド）。予算「1,200,000」、回答期限「2026-12-1」も黙って空（K6・K9）。行の必要数「1,000」「１２」「12個」は 1 にして知らせる（K12。見積の単価は「1,200」「１２００」を数に読むのに、行の必要数は読まない）
6. **良い点（確認できたこと）**
    - ラウンド15 の重大 3 件は、その形ではすべて直った。見積書の形 300 行（x8）は 300 行・数量は数量の列。追加の行がある「変えた行だけ」の表 300 行（x7）は 301 行（変えていない 270 行は旧の値）。「"」だけのセルの .xlsx 300 行（x5）は 300 行、「"」を含むセルいろいろ（z4：`""`・`12"`・`3/4" グランド`・`"N"型`・`a"b"c`・`"始まり`・`終わり"`）も全部そのまま（r15 ビルドは 14 行で後ろの行がつながる）
    - 2 行にまたがって結合した表題・区切り（x1・x11）は外れ、縦横に結合した備考（z5）は左の列だけに入る
    - 「計」＋数字 28 桁＋1 字のセルでプレビューまで 30〜51ms、200 桁でも 101〜119ms（r15 ビルドは 26 桁で 7.1 秒）（`105-redos-xlsx-run1/2.json`・`-5198.json`）
    - 公開を 2 回したあとの Ctrl+Z の 2 回目は「これ以上戻す操作がありません」、やり直したあとの Ctrl+Z は「元に戻す: 公開を戻す（未公開として積む）」（U1・U5、リロードを挟んでも B5）。別のタブが公開し直した行は「戻せません…この公開は戻さずに飛ばしました」（T3・B1・B3・B6、リロード後も）
    - JSON の「1,200」「¥1200」「１２００」・設定の「"5"」・行の必要日・作業中の必要日の時刻つき・0 の無い月日は読む（J1・J4〜J6）、1e20 の文字・負の値は「空にしました」と知らせる（J2・J11・K14）
