## 変更図の削除の判定（N17-01〜03・N17-08・V17-05・V17-06・V17-10）

ラウンド 14〜16 で「書き写す表か」の判定（追加の行の有無 → 1 行でも新旧が同じ → 8 割）が毎回ほかの形を壊したため、表の中身で決める形にした。

- 書き写した行（新と旧がどの項目も同じ）が 2 行以上あり、新の列が空の行より多いか同じ表は「書き写す表」。そこで新の列が空の行は削除
- 新の列の削除の印（削除・廃止・撤去・取外し・不要・不使用・なし・×、括弧・記号つきも）、新の数量の 0 は、ほかの新の列が空・変えていない印・削除の印だけのときに削除（新の型式があって新のメーカが「なし」の行は消さない）
- 備考は、頭が 削除／廃止／撤去／取外し の備考（「削除（Rev.1）」「削除のこと」「削除→不要」「削除（R012 に置換）」）で、新の列が空か変えていない印の行を削除。「撤去後に再取付」「削除しない」「Remove film …」は残す
- 〃は削除する行も含めて上の行から読む（削除した行のすぐ下の〃は、削除した行の値）
