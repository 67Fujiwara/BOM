## 2. 新しい不具合

形式：重大度 / 再現（キー列）/ 期待 / 実際 / 証跡 / 推定原因

### N17-01 【悪化】全行を書き写した変更図（変えない行も変更後の欄に同じ値）で、削除する部品の変更後を空にすると、**削除が 2 行以上（8 割未満）のとき削除した部品が旧の値で取り込まれ公開される**。削除が 1 行なら削除になる
- 重大度：**重大**（削除した部品が問題 0 件で Rev.1 公開され、購買の見積・発注に乗る。削除の数で結果が逆になるので新人には予測できない。知らせは「「型式（新）」が空の 2 行は、ほかの「型式」の列の値を使いました」だけで、削除の言葉が出ない。r16 のビルドでは削除として取り込まなかった）
