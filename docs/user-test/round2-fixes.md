# 利用者テスト ラウンド 2 — 修正対応表

対象レポート: [round2-newbie.md](round2-newbie.md)（新人 100 人）、[round2-mid.md](round2-mid.md)（中堅 100 人）。
ベテランのラウンド 2 は別表（round2-veteran.md の受領後に追記）。

確認: `npx tsc -p tsconfig.app.json --noEmit` 0 件 / vitest 15 件 合格 / Playwright E2E 12 件 合格（新規 2 件: 英字の打ち始め・編集中のビュークリック）。

## 新人（N2 / U2）

| # | 内容 | 対応 |
| --- | --- | --- |
| N2-01 | パレットで「JSON を書き出す」→ 公開が走る | 一致度順（完全一致 > 前方一致 > 部分一致 > キーワード）に並べ、キーワードの逆向き部分一致を短い語だけに制限。購買の発行・設計の公開は確認を経由 |
| N2-02 | `relay` `hello` `nut` の先頭がコマンドになる | 編集できるセルで英字コマンドの直後（350ms 以内）に文字が続いたら、コマンドを取り消して（Undo・画面状態の復元・パネルを閉じる）上書き編集にする。編集欄にフォーカスが移る前の文字も取りこぼさない。j/k/n の連打・x→n などは従来どおり |
| N2-03 / N2-04 | 編集中のビュー・ボタンのクリックで入力が別の行に入る／消える | `setView`・`runCommand`・案件切替・役割切替の前に必ず確定（読めない値なら移らずに理由を表示） |
| N2-05 | 型式あいまいが部品名セルに付く | 種別で対象セルを決める（型式あいまい・廃番・代替提案→型式、メーカ未記入→メーカ、数量見直し→必要数） |
| N2-06 | `?` の一覧をキーでスクロールできない | ↑↓ / j k / PageUp/Down / Space / Home / End でスクロール |
| N2-07 | 案件設定の納期に過去日 | 過去日は「案件納期 2025-01-01 が過去の日付です」で止める。ヘッダーは「n日超過」表示 |
| N2-08 | 購買がガイドで作ると設計担当になる | 作成者は自分の役割の担当者に。設計以外には「行の追加・編集は設計が行います」と案内して 1 すべてを開く |
| N2-09 | 詳細の相見積表の余白 0・折り返し | グリッドの CSS を直下のセルだけに限定（子セレクタ）、相見積表は nowrap + 余白 |
| N2-10 | 未回答の商社に「採用」が出る | スコアの付く見積だけに採用を出す。未回答・辞退はその旨を表示 |
| N2-11 / U2-09 | ガイドの外クリック・リロードで入力が消える | 外クリックは Esc と同じ経路（下書き保存）。開いている間の内容も sessionStorage に保存 |
| N2-12 | 1024 幅でステータスバーが折り返す | nowrap + はみ出しは隠す |
| N2-13 | 2 タブで同じセルを編集すると黙って上書き | 編集開始時の値と確定時の値が違えば止めて知らせる（もう一度 Enter で上書き、Esc でやめる） |
| N2-14 / N-28 | `Part` 見出し・見出しなし 4 列のずれ | `Part`/`Part Name`/`Name` を部品名に。見出しなしは数字の列を数量とみなして左側を当て、判断した対応を警告に出す |
| U2-01 | 役割プロンプトで数字が氏名になる | 数字で役割を選べる（番号も表示） |
| U2-02 | パネルの中で Ctrl+K が効かない | どのダイアログでもパレットを開く（ガイドの途中は保存） |
| U2-03 | 狭い画面でエラー・警告ランプが消える | 自分のボール・エラー・警告・期限超過は残す（900px 未満はエラー・期限超過） |
| U2-04 | 作成直後の `n` が最初の問題を飛ばす | 作成直後は最初の問題セルにカーソルを置き、案内を「カーソルのセルから直し、n で次へ」に |
| U2-05 | 変更セットの理由が Enter で「客先要求」になる | 理由（変更セット・1 位以外の採用・先行採用）は既定なし。数字か ↑↓ で選ぶまで進まない |
| U2-06 | 隠した行が 4 要確認から消える | 1・4・7 は隠した行も表示。パレットに「行を隠す / 隠した行を戻す」 |
| U2-07 | 詳細の順位番号と並びが一致しない | 詳細の表・↓ の選択とも順位順（未回答・辞退は後ろ） |
| U2-08 | JSON 読み込みにファイル選択が無い | 「ファイルを選ぶ」ボタンと JSON 向けの案内 |
| U2-10 | 案件設定を Esc で黙って破棄 | 未保存の変更があれば 1 回目の Esc で知らせ、2 回目で破棄 |
| U2-11 | 編集中のリロードで入力が消える | beforeunload で確定。読めない値なら離脱確認 |
| U2-12 | Ctrl+G で回路記号・`r30` で探せない | `r30`→R030、回路記号は区切りごと・前方一致でも当たる |
| U2-13 | パレットの言い換え不足 | やり直し・ソート・フィルタ・文字を大きく 等を追加。並び替え・絞り込み・列・ジャンプ・隠す/戻す をパレットに |
| U-04 | ステータスバーのヒント・詳細の指摘が押せない | ヒントはクリックでそのキー操作、詳細の指摘・見積はクリックで選択・ダブルクリックでアクション |
| U-14 | リロードでビュー・カーソルが戻る | ビュー・カーソル・並び・列・最近のコマンドをタブごとに保存（Undo 履歴は前回から保存済） |

## 中堅（M / U）

| # | 内容 | 対応 |
| --- | --- | --- |
| M-01 | 上長決裁の入力が決定に渡らない | プロンプトの追加欄（承認者・日付・決裁書 No.）を決定処理へ渡す |
| M-02 | 「あとで」を解除できず公開不能 | Shift+→ で切り替え、確認済みにすると解除。公開のゲートは有効な「あとで」だけ |
| M-03 | パック単位で入数の倍数に切り上げ | 単位がパックの行は入数で丸めない（スコア・ルールとも） |
| M-04 / M-05 | スコアの基準数量・納期式 | 基準数量＝公開済の必要数を MOQ・入数で丸めたもの、基準日＝見積日、余裕 ≥0 で 100・不足は日数で線形 |
| M-06 | g/d/q が直後に打ち消される | 再交渉は正式単価をクリア、d/q は営業日で期限を付けた指摘を起票し差分超過キーを記録 |
| M-07 | 先行発注許可で推奨が採用されない | 許可時に推奨を自動採用 |
| M-08 | 差分超過の行を `o` で発注できる | 差分超過・PM 承認待ち・納期NG の行は決定まで発注不可 |
| M-09 | 承認待ちの設計変更が購買に見える | 承認が要る変更セットは pendingApproval に保留し、承認で反映・却下で作業中に戻す |
| M-10 / M-22 | 購買・PM に設計の作業中の値が出る | 役割ごとの値（設計だけ作業中の値）で表示・金額・スコア・Excel を計算 |
| M-11 | 設計の 4 要確認の対象違い | 4 は役割ごと（自分のボール＋設計は問題・拮抗、購買はフラグ・指摘・下書き） |
| M-12 | 5 変更ありが最新 Rev だけ | Rev 横断の未確認差分、起因列を追加 |
| M-13 | 集約試算・適用の誤り | 有効な見積だけで試算、作業中・承認待ちの行は対象外 |
| M-14 | パレットの先頭が別コマンド | N2-01 と同じ |
| M-15 / U-06 | PM の氏名が設計者のまま | ガイドで PM 担当者を聞く。役割切替の既定名はその役割の担当者 |
| M-16 | 正式見積の差分判定 | 「±10% と ¥10,000 の大きい方」を超えたら差分超過 |
| M-17 | 対策不成立が差分超過として載る | 「対策不成立」の要決定として専用の選択肢 |
| M-18 / M-20 / M-21 | 発注済の b/p、次点の選び方、委譲後の選び直し | 発注済には b/p を出さない、次点は必要日を満たす商社から、委譲された購買は正式依頼中でも選び直せる |
| M-19 | 自動起票の納期NG の担当が購買 | 担当は設計 |
| M-23 | 案件設定確定が 7 に出ない | 7 の先頭に案件の要決定として表示（y で確定・Enter で設定を開く）、件数にも含める |
| M-24 | 取込が数値を検証しない | 読めない値はエラーで止め、型式不一致は上書きせず取込不一致フラグ |
| M-25 / M-37 | 商社向け Excel に社内情報・ボールの表示 | 社内シートは社内向けだけ、ボール無しは空欄、隠した行は保管用だけ |
| M-26 | 提案適用の新行で要再確認が選べない | 提案商社は「提案値」、他は「再見積」を既定に Ctrl+. から選べる |
| M-27 / U2-17 | 番号キーの不一致・二重番号 | 仕様の番号に固定、表示は 1 つ |
| M-28 | 提出後の行追加等が変更セットを通らない | 初回提出後の追加・取消は変更セットとして理由・PM 承認を通す |
| M-29 | 影響試算に総額差・特急費が無い | 追加 |
| M-30 | Alt+A が理由なしで先行採用 | 理由を聞く |
| M-31 | 最小ロットのテンプレが MOQ を見ない | MOQ の見積から余剰数・金額を出す |
| M-32 / M-33 | 拮抗の扱い | 依頼の確認に拮抗を含む件数、境界は 5 点以内 |
| M-34 | 期限が暦日 | 営業日 |
| M-35 | 任意メーカ・代替不可の提案 | メーカ指定が任意なら提案を生成 |
| M-36 | 余剰金額が無い | スコア内訳・詳細に余剰金額 |
| M-38 | 複数代替提案の片方適用 | 他は「見送り（I-0xx を適用）」 |
| U-01 | 6/8 で数字を続けて打てない | 6 商社別・8 正式見積の数値セルでは数字はそのまま入力 |
| U-02 / U-03 | 理由で数字が効かない・エラーで閉じる | 数字で選択、エラーは入力を残して開き直す |
| U-04 | 設計待ちの内訳 | ヘッダーの設計待ちに「指摘の対応・選定待ち・その他」 |
| U-05 | Undo 履歴がリロードで消える | タブごとに保存 |
| U-07 | 起票パネルで J が本文に入る | 本文で Ctrl+Enter＝起票して次の行で同じ種別の本文から続ける |
