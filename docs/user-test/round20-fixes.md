# 利用者テスト ラウンド 20 — 修正対応表

## 新人（N20）

| 不具合 | 症状 | 直し |
|---|---|---|
| N20-01（重大・ラウンド 19 の副作用） | ふつうの型式の「→」「>」（`USB-A→USB-C 変換ケーブル`・`(赤→黒)`）の左が捨てられる | 「旧→新」と読むのは、→ の両側が空白なしの英数字の語（MY2N→MY4N-D2・1→2）のときだけ |
| N20-02（重大・ラウンド 19 の副作用） | 変更内容・変更理由と備考の両方があると備考が捨てられ、備考の「削除」が効かない | 備考の列を変更内容・変更理由の列より先に。「取付位置変更」などの理由は変更内容の列も見る |
| N20-03（重大・ラウンド 19 の副作用） | 書き写した表で「－」の削除が書き写しと同数だと、印も警告も無く取り込む | 「－」の行も空の行と同じに、決められない表では【削除？】を付けて聞く |
| N20-04 / N20-07（重大） | 「削除（保留）」「削除（しない）」「撤去（再取付）」が削除になる。「削除お願いします」「削除です」が何の印も無く残る | 削除の言い方を 3 つに分けた: 削除と断定できる／残すと断定できる／決められない（頭が削除・廃止・撤去・取外しなのに言い方が合わないもの）は【削除？】で聞く。注記の中が否定・保留・再利用なら残す。です・お願いします・完了・ずみ・となります・Rev.B:削除・(Rev.2)削除・使用しない も削除 |
| N20-05 | 変更区分の「削除済」「削除品」「×」「不要」「撤去済」「Deleted」「除却」「D」、〃、見出し「変更の種類」「ECN区分」を読まない | 削除の言い方を広げ、〃は上の行と同じ区分、見出しを追加 |
| N20-06（ラウンド 19 の副作用） | 備考の「未実装品」「未実装部品」「未実装です」「非実装品」が外れない | 品・部品・です・こと・予定 までを許す（部品名「未実装基板」・「未実装時は短絡」は残す） |
| N20-08 / N20-09 | 「ｽｳﾘﾖｳ」（大きい ﾖ）、「第1号機」「Unit1」を数量・号機に読まない | 見出しの読みを追加、第n号機・Unit n を号機に（Unit1 は単位にしない） |
| N20-10（ラウンド 19 の副作用） | 部品名「DNP 反射フィルム」が外れる | DNP は単独か括弧の注記つきのときだけ |
| U20-02 | 【削除？】の案内が非表示の備考の列を指す | 直し方（Ctrl+. で「要る部品」・Shift+Delete）と列の出し方を案内 |
