## 2. 新しい不具合

形式：重大度 / 再現（キー列）/ 期待（仕様の §）/ 実際 / 証跡 / 推定原因（file:line）

共通の原因：商社マスタに無い商社 ID を「取引できる」と読む `suppliers.find(…)?.tradable !== false`（見つからないと `undefined !== false` で真）が、`score.ts`・`derive.ts`・`quotes.ts`・`adopt.ts`・`lifecycle.ts` の 15 か所ほどにある。M20-05 の修正は `lifecycle.ts:73` の採用の外しだけに入り、**案件の相見積先 `supplierIds`（`validate.ts:143` は検証なしで受ける）・商社の見積（`p.quotes`）・客先指定品の指定先の決定は消えた商社を指したまま**。商社を消す操作は JSON の読み込みしか無いが、読み込んだ直後から次の 5 件が出る。

### M21-01 マスタから消えた商社を指定先にした「客先指定品」の行が、その商社のまま採用に戻り、正式見積を依頼すると例外で止まる
- 重大度：**中**（正式依頼の途中で止まる。依頼書が作られないのに行は正式依頼中になる）
- 再現：一括採用 → 購買 正式見積を依頼（R034 などが因幡 S1 で正式依頼中）→ `Ctrl+K →「JSON を読み込む」` で商社マスタから S1 を除いた JSON → 置き換える → 設計 `未採用を推奨で一括採用` → 購買 正式見積を依頼
