## 2. 新しい不具合

### N3-01 Shift を押して大文字で打ち始めると、先頭の Shift+英字がコマンドとして実行されたまま残り、残りの文字が別の行・新しい行に入る（先頭の 1 文字は消える）
- 重大度：**重大**（型式・メーカは大文字始まりが普通。別の行の型式が黙って書き換わり、そのまま公開すると指摘まで「対応済」になる）
- 再現（設計、ビュー 1、Excel と同じく Enter を押さずにいきなり打つ）：
  - R043 メーカで `Shift+N` `E` `C`（「NEC」）→ `Enter`
  - R045 メーカで `Keyence`、R050 部品名で `Jumper`、R059 型式で `SJ-4`、R046 メーカで `Denso`、R044 メーカで `SMC`
  - 購買の指摘「型式あいまい」が付いた R030 型式で `S-T21 AC200V` → `Enter` → `Ctrl+Enter` → `2` → `Enter`
- 期待：Excel と同じく打った文字で上書き編集が始まる（小文字は N2-02 の修正で直っている）
- 実際（`results/t04_typing2.out`）：
  - `NEC`：Shift+N（前の問題へ）で **R061 型式へ移り、R061 の型式が「EC」になる**（R043 は変わらない）
  - `Keyence`：Shift+K（前の行）で **R044 のメーカが「eyence」**
  - `Jumper`：Shift+J（次の行）で **R051 の部品名が「umper」**
  - `SJ-4`：Shift+S（降順に並び替え）→ Shift+J（次の行）で **R058 の型式が「-4」**、並び替えも残る
  - `Denso`：Shift+D で **R046 を複製した R081 ができ、そのメーカが「enso」**

  - `IDEC` / `Inverter` は Shift+I で指摘パネル、`Analog` / `Antenna` は Shift+A で商社選択パネルが開き、残りの文字はパネルに吸われる（数字を含む語なら商社を選んでしまう）
