## 英字の扱いの作り直し（新人 N4-01/02/03/04、ベテラン V4-01/02/03/04、V3-02）

これまでの「コマンドを実行してから、続けて文字が来たら取り消す」方式は、ダイアログを開くコマンド・Shift 付き・ゆっくり打つ・重い画面で、どちらかの向きに必ず取りこぼしが出た。次の方式に変えた。

- 文字を打てるセルで、移動以外の英字コマンド（Shift 付きも）は **すぐには実行せず 0.4 秒待つ**。その間に文字が来たら値の打ち始め（コマンドは実行していないので取り消すものが無い）。来なければ実行する。
- 次のキーがコマンドの続きなら待たずに実行する: j（a → j）、母音以外のあとの k / n（x → n、h → k）、小文字のコマンドのあとの数字（s → 4）。値の続き: 母音のあとの k / n（anode・ok）、大文字（Shift）のあとの数字（A1・K8AK）。
- 直前 1.5 秒以内に英字コマンドを実行していれば待たない（x → n → x … の連続操作）。
- 移動キー（j / k / n の小文字）はすぐ動かし、間をおかずに別の英字が続いたら移動を戻して値にする（knob・kit）。間をおいた英字コマンド（n で問題に飛んでから x）はコマンド。
- 間隔はキーを押した時刻（イベントの時刻）で測る（重い画面で処理が遅れても、打つ速さで判定）。
- クリックしたときは、待っているコマンドを先に実行する（別の行に効かない）。
- `r`（置換）も待つので、`r` の後に一呼吸おけば「置き換え品を作る」のダイアログに型式を打てる（V3-02）。
