## 2. 新しい不具合

形式：重大度 / 再現（キー列）/ 期待 / 実際 / 証跡 / 推定原因

### N4-01 型式・メーカに Shift+A で始まる値（AC100V・A1・A2-1 など）を打つと、商社を採用し、残りの文字が型式に入る
- 重大度：**重大**（打っただけで行が「選定済」になり、型式が書き換わる。Esc で抜けても採用は残る）
- 再現（設計、ビュー 1）：`Ctrl+G R049` → 型式列へ → いきなり `Shift+A` `Shift+C` `1` `0` `0` `Shift+V`（AC100V）→ `Enter`。R056 型式で `Shift+A` `1`（A1）
- 期待：打った文字がそのセルに入る（Excel と同じ）
- 実際：Shift+A で「商社を選んで採用」が開き、`1` で第 1 商社を採用。**R049 は見積済 → 選定済（因幡電機、発注数 100）になり、続く「00V」で型式が「00V」**になる（作業中）。A1 は R056 がミスミで採用。A2-1 は 1 位以外の理由パネルまで進む。通知は「R049 を 因幡電機 で採用」だけ
- 証跡：`results/t02_panelwords.out`（AC100V / A1 / A2-1）、`shots/t02_R049_AC100V.png`、`shots/t02_R056_A1.png`
- 推定原因：`src/commands/keyboard.ts:598`。Shift+A（adopt.choose）・Shift+I・c・w でパネルが開いたときは「続けて打った文字」の判定（burst）を捨て、次の数字をパネルの選択として通している（「Shift+A → 2 のような速い操作をそのまま通す」）。文字を打てるセルでは打ち始めと区別できない

### N4-02 c・w・Shift+I で始まる語（cable / connector / capacitor / cord / wire / washer / IDEC / Inverter / IC socket）を打つとパネルが開いて値が入らない（c・w はラウンド3 では入っていた）
- 重大度：**中**（**悪化**。部品名で一番よく打つ語が入らない。IQ sensor のように o・q を含む語では下書きの指摘ができる）
- 再現（設計、ビュー 1）：R035 部品名でいきなり `cable` → `Enter`。R036 で `wire`、R035 で `connector`、R036 で `capacitor`、R037 で `washer`、R042 メーカで `Shift+I` `Shift+D` `Shift+E` `Shift+C`（IDEC）、R040 部品名で `IQ sensor` → `Enter`
- 期待：打った語がそのセルに入る（ラウンド3 では cable・wire は「続けて打たれたので「c」はコマンドではなく文字の入力として扱いました」で入った）
- 実際：
  - cable / connector / capacitor / cord：列の表示パネルが開き、残りの文字はパネルに入る。Enter で「ID と部品名は隠せません」。値は変わらない
  - wire / washer / w1：「この行だけ重みを変える」パネルが開いたまま
  - IDEC / Inverter / IC socket：指摘の起票パネル。Enter で種別「質問」に進む
  - IQ sensor → Enter：途中の o で種別「その他」になり、**Enter で I-006「その他」の下書き指摘ができる**
- 証跡：`results/t01_typing.out`（cable・wire・connector・capacitor・washer・IDEC・Inverter・IC socket）、`results/t02_panelwords.out`、`shots/t01_fast_R035_cable.png`、`shots/t01_fast_R036_wire.png`、`shots/t02_R040_IQ_sensor.png`、ラウンド3 の `usertest/newbie/r3/results/t01_typing.out:28-33`
- 推定原因：`src/commands/keyboard.ts:598`（N4-01 と同じ。columns.panel・weights.row・issue.raise を burst の対象から外している）

### N4-03 回路記号に K1・J3・N2・k5・j2 と打つと、行が移ってビューが切り替わり、値は入らない。「NN-1」は別の行の型式に入る
