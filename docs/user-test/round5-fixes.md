対象レポート: [round5-mid.md](round5-mid.md)（中堅）、[round5-newbie.md](round5-newbie.md)（新人）、[round5-veteran.md](round5-veteran.md)（ベテラン）。新人・ベテランのテストは、英字の扱いを「待ち時間」で判定していたコードで行った。

## 英字の扱い（新人 N5-01〜05・N4-01〜04・U3-06、ベテラン V5-01〜05・V4-01〜03・V3-01）

ラウンド 2 から 5 まで、打つ速さ・Shift・1 文字の値・小文字の型番などで、毎回どちらかの向きに取りこぼしが出た（待ち時間・取り消し・続けて打つ組み合わせの判定のどれも、遅く打つ人と速く操作する人の両方は満たせない）。時間で判定するのをやめ、次の決まった規則にした。

- **文字を打てるセル（いまの役割で編集できる文字・数値・選択・日付の列）では、英字は（Shift 付きも、1 文字でも、何秒あけても）値の打ち始め**。仕様の「編集：いきなり文字を打つ」と同じ。
- 英字のコマンドは、文字を打てないセル（ID・ボール・状態・自動計算の列、他の役割の列）ではそのまま。**どのセルでも Alt を押しながら**使える（Alt+x 確認済み、Alt+h 隠す、Alt+Shift+I 指摘、Alt+Shift+A 商社を選ぶ）。Alt+A は仕様どおり「最安で採用」のまま、推奨で採用は Ctrl+Alt+A でも使える。次の問題・前の問題は F8 / Shift+F8 でも使える。
- ステータスバーのヒントは、文字を打てるセルでは Alt 付き（F8・Ctrl+Alt+A）で出す。`?` の一覧の冒頭にこの規則を書いた。
- 数字はこれまでどおりビュー切替（§9.1）。

この規則では、文字を打てるセルで英字のコマンドを続けて使う（x → n → x …）ときは Alt を付ける（ID の列にいれば Alt は要らない）。速く打つ人の連続操作と、新人の打ち間違いのどちらも、速さに左右されずに同じ結果になる。
