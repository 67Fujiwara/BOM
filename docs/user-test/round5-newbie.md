### N5-01 Shift+A・Shift+I のあとに n が続く語（Analog Devices・Anritsu・Infineon・Inverter・Antenna）は、速く打っても商社の採用・指摘の起票になる
- 重大度：**重大**（打って Enter を押しただけで、別の誰にも見える「選定済」と発注数が記録される。メーカ欄でよく打つ名前）
- 再現（設計、ビュー 1）：`Ctrl+G R043` → メーカ列 → いきなり `Shift+A` `n` `a` `l` `o` `g` `Space` `Shift+D` `e` `v` `i` `c` `e` `s`（1 字 40ms）→ `Enter`。R044 で `Anritsu`、R042 で `Infineon`、R039 部品名で `Inverter`、R058 部品名で `Antenna`
