## 1 キー操作の規則（仕様 §14.1 v0.3）

ラウンド 5 の「文字を打てるセルでは英字は値」を、次のように決めた（新人 N6-01〜04・U6-01〜02、中堅 U6-02、ベテラン V6-01・V6-02・V6-05〜07）。

- **素の英字・数字が 1 キー操作になるのは、ID・状態・チェックの列だけ**。他の役割の列・自動計算の列でも、英字・数字は操作にせず「この列は編集できません。1 キー操作は Alt を押しながら（例: Alt+x）か、ID の列で」と知らせる（購買が備考に「ok」と打って発注済になる、設計が単価に「sale」と打って採用になる、を防ぐ）。数字で始まる型式（1N4148・2SC1815・3M）も打てるセルでは値。
- **Alt+英字・Alt+数字はどの列でも操作**。Alt+a は「推奨で採用」（a と同じ）、最安で採用は Ctrl+Alt+A。次・前の問題は F8 / Shift+F8。
- **行を選んでいないとき**（起動直後・JSON 読み込み直後・絞り込み 0 行）は数字（ビュー切替）だけ。英字は「行を選んでください（↓ で先頭の行へ、F8 で最初の問題へ）」と出して何もしない（`Knowles` の `K` で最後の行へ飛び、残りが別の行に入る、を防ぐ）。JSON の読み込み・戻しのあとは先頭の行を選ぶ。行を隠してビューから消えるときは、カーソルを次の行（無ければ上の行）へ移す。
- **ID・状態の列で F8 / n を押しても列は ID のまま**（同じ行の別の問題は飛ばして次の行へ）。`x n x n …` が最後までコマンドになる。
- Alt を押したまま Alt+英字のコマンドを続けている間は、Alt+↑↓ を行の移動にせず ↑↓ にする（Alt を離すか押し直すと、もとの行の移動）。Alt+数字はビュー切替。
- 割り当ての無い Alt+英字・Ctrl+Alt+英字・Alt+Home / End はブラウザの既定動作（アドレスバー・メニュー・ホームへ移動）を止め、「Alt+D は割り当てがありません」と出す。
- 案内文・ステータスバー・パレット・ヘルプは F8・Alt+… の形で書く（「n で次の問題へ」「h でもう一度」「f か Esc で解除」「x で受け入れ」などを直した）。ヘルプは「alt」「f8」「英字」でも引ける。狭い画面でもステータスバーの「Ctrl+Enter 公開」「? ヘルプ」を先頭に出す。
