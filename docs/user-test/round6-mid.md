### M6-01 客先指定品で、依頼先がまだ答えていないうちに別の商社の欄に値を入れると、その商社が「指定先（固定）」で採用される（M4-06 の再発）

- 再現：設計 `1` で客先指定品（オムロン G2R-1 DC24、指定先「客先承認 KS-1」）を追加して公開 → 購買 `Ctrl+K → 概算見積を依頼`（既定の依頼先＝オムロンを扱う第 1 商社の因幡に依頼書）→ `6` で **立花** の単価 500・納期 3 を先に入れる → 因幡の単価 800・納期 5 を入れる
