## 3. 使い勝手（不具合ではないが、ベテランが引っかかる点・確認できた良い点）

1. **英字の新しい規則は、行を選んでいる限り完全に予測どおり**：46 語 × 0〜1,000ms × 開発・ビルドの 368 回、Alt 付きの連続コマンド 200 回がすべて期待どおり。ラウンド2〜5 の「打つ速さで結果が変わる」は無くなった。Alt 付きの英字コマンドは 8〜9ms で反応し、0.4 秒の待ちも無い。ステータスバーのヒントも文字を打てるセルでは「Alt+x」「Ctrl+Alt+A」「F8」に変わる
2. **j / k で行を動くベテランは、文字を打てる列では「j」「k」が入る**（設計どおり）。vim 式の移動は ID・状態の列か Alt+j / Alt+k に限られる。↓ / ↑ で代わりになるが、`?` の一覧の冒頭以外に案内が無いので最初は戸惑う
3. **Alt+a と a が違う操作**：ID 列では `a` は推奨で採用、`Alt+a` は最安で採用（`52-altmatrix`：R040 が `a` / `Ctrl+Alt+A` では因幡電機、`Alt+a` ではミスミ）。「Alt を付ければ同じ」と覚えた人は、文字を打てる列で `Alt+a` を押して最安で採用してしまう。`Ctrl+Alt+A` は Windows の一部のキー配置（AltGr）や常駐アプリの画面取り込みと重なることがある（環境依存）
4. **編集中は Alt 付きの英字・F8 が何もしない**（確定もしない）。Ctrl+K などは「確定してから実行」なのに、Alt+x・F8 は黙って無視される（`53b-editkeys`）。Excel の Alt+Enter（セル内改行）も何も起きない
