## 中堅（M7）

| # | 内容 | 対応 |
| --- | --- | --- |
| M7-01 / U6-04 | 指定商社の指定先を商社名で書いた行の辞退が行き止まり。指定先を変える案内が無い | 名前でも ID でも辞退を見て設計に回す。Ctrl+. とステータスバーに「指定先を変える」 |
| M7-02 / U6-05 / U7-03 | メーカの表記ゆれ（OMRON・omron・オムロン株式会社・三菱）で扱う商社に頼まれず、ミスミ 1 社だけに。辞退後の次の依頼先も扱わない商社に。結果に絞り込みの説明が無い | 英字の大小・全角・会社の種類・カナと英字・前方一致を同じメーカとみる。扱う商社がマスタに無ければ全社に頼む。依頼の結果に「メーカを扱わない商社には頼まない行」「扱う商社が無く全社に依頼した行」を出す |
| M7-03 | 承認で外した発注を、取引先が取消を断ったときに戻せない（ラウンド 6 の修正の副作用） | 購買の「キャンセル不可で発注に戻す」（確認つき）。発注を止める理由の文にも案内 |
| M7-04 | 再交渉のあと数量変更で概算から取り直すと、再交渉の印が残り納期NG が見えなくなる | 見積中より前に戻ったら再交渉の印を外す |
| U6-01 | 特急・分納の上限超えがトーストだけ | 購買の 4・PM の 7 に出す |
| U6-03 | PM の判断で止めた Ctrl+Z / Ctrl+Y が「別の操作で変わった」と出る | 決まりで止めたときは理由をそのまま出す。Ctrl+Y の文も Ctrl+Z とそろえた |
| U7-02 | 購買の 4 で辞退した客先指定品の次の手が分からない | Ctrl+. とステータスバーに「次の商社に依頼」 |
