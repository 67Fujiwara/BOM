## 2. 新しい不具合

形式：重大度 / 再現 / 期待 / 実際 / 証跡 / 推定原因（file:line）。特記の無いものは開発（5176）で再現し、キーの扱いはビルド（5197）でも同じ。

### V7-01 記号で始まる値（`?` `/` `[` `]` `<` `>`・先頭の空白）を文字を打てるセルで打つと、1 文字目がコマンドになり、残りが**別の列・別の行**・絞り込み欄に入る
- 重大度：**中**（英字・数字は v0.3 の規則で「文字を打てるセルでは値」になったが、記号は対象外のまま。備考の「<5mm」「>85℃」「?要確認」「[代替可]」、型式の「[A]…」のように、BOM の値として普通に打つ。Enter まで打つと、打ったつもりのセルではなく別のセル・別の行が書き換わる）
- 再現（実打鍵 40ms 間隔、設計・1 すべて・R040）
  - 備考で `<5mm` → `<` で **5 変更あり（前の Rev）へ切り替わり**、カーソルは R040 の部品名、残りの `5mm` が部品名の編集欄に入る → Enter で **R040 の部品名が「5mm」**
  - 備考で `>85℃` → 同じく 5 へ、部品名に「85℃」
  - 型式で `[A]CN-12` → `[` で前の分類の見出し、`A` `]` `C` `N` `-` は「行を選んでください」、`1` で 1 すべて（R001 型式へ）、`2` が **R001 の型式の編集欄** に入る → Enter で **R001 の型式が「2」**
  - 必要数で `<10` → 5 へ切り替わり、必要数の編集欄に「10」
  - 備考で `?要確認` → ヘルプが開く。`/N 指定` → 絞り込み欄に「N 指定」が入り、表が 0 行になる（カーソル「—」）。`[代替可]` → 分類の見出しへ。先頭が空白 → 行が開く
  - `#2 ロット`・`-40℃` は値として入る（`#` `-` には割り当てが無い）
- 期待：英字・数字と同じく、文字を打てるセルでは記号も値の打ち始め（`?` `/` `[` `]` `<` `>` `Space` のコマンドは ID・状態の列か、Alt 付き・別のキーで）。少なくとも 1 文字目で別のビュー・別の行へ移さない

## 3. 使い勝手（不具合ではないが、ベテランが引っかかる点・確認できた良い点）
