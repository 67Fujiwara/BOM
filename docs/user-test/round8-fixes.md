## 1 キー操作の規則（仕様 §14.1 の見直し）

ラウンド 7 で足した「書ける列が無いビューではどの列でも 1 キー操作」「書けない列の数字はビュー切替」は、打った単語の 1 文字目でビューが変わり、残りが切り替えた先の文字を打てるセルや別の行に入る・単語の各文字が操作になる、という形で新人・ベテランの両方に出た（N8-01・V8-01・V8-02）。次のように狭めた。

| # | 内容 | 対応 |
| --- | --- | --- |
| N8-01 | 購買が書ける列の無いビューで単語を打つと入荷済・隠すなどの操作になる | 「書ける列が無いビューではどの列でも 1 キー操作」をやめた。どの列でもそのまま効くのは PM の `7` の `y` / `Shift+Y` と、PM の数字（ビュー切替）だけ |
| V8-01 | 書けない列で数字を打つとビューが変わり、残りが切り替えた先の部品名に入る | 書けない列の数字は案内だけ（「要確認」は Alt+4）。PM はどの列も書かないので数字でそのまま切り替え |
| V8-02 / N7-02 | 行を選んでいないときの `47`・`2SC1815` で、切り替えた先の先頭の行に残りが入る | 行を選んでいないときに数字で切り替えたら、行は選ばないまま（↓ で表へ） |
| N7-01（残り） | 単語を打つと、案内の「例: Alt+○」が最後の文字になり、案内どおり押すと別の操作 | 案内に操作の名前を書く（「入荷済」は Alt+i） |
| N8-02 / V8-07 | 画面の固定の文が `?`・`/` を案内し、文字を打てるセルで値になる。F1 が編集中・入力欄で Chrome のヘルプを開く | ヘルプは F1、絞り込みは Ctrl+F で案内（編集中も効く）。F1 はどこでもブラウザのヘルプを止め、絞り込みの欄からもキーの一覧 |
| V8-06 | macOS で Option+記号（÷ ¿ “）になり Alt+/ などが効かない | キーの位置から記号の操作を引く |
| N8-03 / V7-03（残り） | 直して Enter → F8 が先頭の問題へ戻る。直して公開待ちの指摘が一覧に残る。4 で直すとカーソルが先頭へ。リロード後・Ctrl+G の後も先頭から | 直した行がビューから外れたら同じ位置の次の行へ。F8 は前に飛んだ位置から続け、Ctrl+G などで飛んだ後・リロード後はカーソルより下の最初の問題へ。直して公開待ちの指摘は飛ばす |
| V8-03 | 別のタブの変更で行がビューから外れると、黙って隣の行へ移り、続けたキーが別の行に効く。編集中は入力欄が消える | 別のタブの変更なら行の選択を外して知らせる。編集中の入力は保存せずに知らせる（自分の操作なら次の行へ） |
