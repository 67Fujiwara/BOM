## 1 キー操作・入力

| # | 内容 | 対応 |
| --- | --- | --- |
| N9-05 | 「数字か ↑↓ で選び、理由を入れて Enter」のダイアログが数字で確定し、続けた文字が表に入る | 文字欄もあるダイアログでは数字は選ぶだけ。確定は Enter |
| N9-03（一部） | 発注・入荷の列で打った語が操作になる（zumi → 入荷済） | 発注・入荷の列は Enter で切り替え、打った文字は案内だけ。ID・状態の列の英字は仕様どおり 1 キー操作（Ctrl+Z で戻せる） |
| N9-04 / V8-02（残り） | 分類の見出し・行を選んでいないときの数字・記号で選択が外れる／「<5mm」の残りが R001 に入る | 見出しの行は [ ] だけ、行を選んでいないときは数字だけ。ほかは案内 |
| U（ベテラン） | 書けない列の記号が操作になる（11/30 の / で絞り込みが開いて 30 が入る） | 書けない列では記号も案内だけ。どの列でも Alt＋記号 |
| V9-01（ラウンド 8 の修正の副作用） | 4 を開いて F8・Ctrl+G の後の F8 が一覧の順で、近い問題を飛ばす | 見えている並びで、カーソルの行から下（Shift+F8 は上）でいちばん近い問題へ |
| V9-02（ラウンド 8 の修正の副作用） | 4 で直して Tab・Ctrl+. で抜けると、隣の行の同じ列に続けて書く | Enter なら次の行へ、Tab・Ctrl+. などでは行の選択を外して止める（順番に直すモードは次の問題へ進む） |
| N8-03（残り） | Ctrl+. →「編集する」で F8 の位置を忘れる | 直し方の候補から問題のセルへ移るときは位置を続ける |

| V9-08（JIS 配列） | Alt+@ が前の分類へ | 位置で引くのは OS が ASCII 以外の文字を作ったとき（macOS の Option）だけ |
| N9-06 / N9-07 / N9-08 / U6-02 | ヘルプの冒頭・ガイドの貼り付け欄・「あとで」・並び替えの説明が今の規則と合わない | 書き直した |
| U9-01（新人） | 購買が 6・8・9 を開くと部品名で、単価を打っても「権限なし」 | 書けない列にいるときは、ビューを開いたら自分が書ける最初の列へ（6・8 は単価、9 は発注数） |
| U9-03 / U9-04（新人） | 見積の言葉（あり・即納・営業日・令和）を読まない、過ぎた有効期限・依頼前の正式単価を黙って入れる | 読むようにした。過ぎた有効期限・依頼前や概算から ±50% 以上の正式単価は知らせる |
