  2. **M9-02 / M9-03 見積の枠を「依頼したとき」に作る修正の取りこぼし**。依頼書なしで回答を入れ始めた行は残りの商社に依頼書を出せず（頼んでいない商社を待つ）、逆に 1 社だけ依頼した行は「2社以上」「全社」でも 1 社の回答で見積済になる。「どの商社に依頼したか」を枠の有無ではなく記録で持ち、完了条件の分母は行の相見積先にする
  3. **M9-04 採用を外した行に納期NG が残り、PM の 7 に載る**（あわせて M9-05 の指定商社が見積済・先行発注判断になる件）。採用を外したら納期NG・対策区分・先行発注判断を外し、状態は見積完了条件で決め直す
- そのほか M9-07（承認待ちの追加行に取り込みで見積が入る）は M8-03 の修正が手入力だけに入った残り、M9-09 は M8-07 の修正（商社マスタから次の依頼先）が取引可を見ず、使い切った後の行き止まりが残ったもの
